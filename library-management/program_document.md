# Flask图书管理系统软件开发工程书

## 1.项目概述

### 1.1项目背景 
  随着图书馆藏书的不断增加和读者需求的多样化，传
统的手工管理方式已无法满足现代化图书馆的管理需求。
本项目旨在开发一个基于Flask框架的图书管理系统，
实现图书信息的数字化管理和高效服务。

### 1.2项目目标
- 实现图书信息的集中管理和快速检索
- 提供便捷的借阅、归还流程
- 支持多用户角色权限管理
- 提供数据统计和分析功能
- 构建用户友好的Web界面

### 1.3技术栈
- 后端框架: Flask + Python
- 前端技术: HTML5 + CSS3 + JavaScript + Bootstrap
- 数据库: SQLite/MySQL
- ORM: Flask-SQLAlchemy
- 认证授权: Flask-Login
- 表单处理: Flask-WTF
- 部署: Gunicorn + Nginx

## 2.项目需求分析

### 2.1功能分析

#### 2.1.1用户管理模块
- 用户注册、登录、注销
- 用户信息管理（个人信息修改）
- 角色权限管理（管理员、普通用户）

#### 2.1.2图书管理模块
- 图书信息添加、修改、删除

#### 2.1.3借阅管理模块
- 图书借阅流程
- 图书归还流程
- 借阅记录查询
- 逾期管理和提醒

#### 2.1.4数据统计模块
- 借阅统计
- 图书流通分析
- 用户借阅行为分析

### 2.2非功能需求
- **性能要求**: 系统响应时间<3秒

- **可用性**: 99%以上的系统可用性
- **可扩展性**: 支持后续功能扩展

### 5.2 测试用例示例
```python
def test_book_borrow():
    # 测试借书功能
    user = User.query.get(1)
    book = Book.query.get(1)
    initial_count = book.available_copies
    
    # 执行借书操作
    borrow_book(user.id, book.id)
    
    # 验证结果
    assert book.available_copies == initial_count - 1
    assert BorrowRecord.query.filter_by(user_id=user.id, book_id=book.id).first() is not None
```
